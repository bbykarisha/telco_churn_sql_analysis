## Анализ оттока клиентов Telco

Проектирование базы данных и анализ оттока клиентов телеком-компании на 
датасете Telco Customer Churn преимущественно с помощью языка SQL.

Датасет содержит 7043 записи и 21 атрибут.

### Инструменты

PostgreSQL, DBeaver, Python, pandas, numpy, SQLAlchemy, DuckDB.

### Файлы

- `telco_ddl.sql` — создание и заполнение справочников,
  создание таблицы клиентов и ограничений.
- `transform_data.ipynb` — подготовка и анализ основной таблицы клиентов средствами Python и подключение к PostgreSQL.
- `telco_customer_churn.drawio` — ER диаграмма в drawio
- `queries.sql` — девять различных SQL-запросов с результатами и интерпретациями.
- `duckdb_queries.sql` — загрузка исходного плоского CSV и запросы для DuckDB.

### Что сделано

- Спроектирована схема PostgreSQL: таблица customers и три справочника.
- Подготовлен DDL с первичными и внешними ключами,
  проверками значений и правилами обработки NULL значений.
- Выполнены девять SQL-заданий: агрегирование, представления,
  транзакции, подзапросы, JOIN и экспорт аналитической витрины.
- Два запроса перенесены в DuckDB, результаты сравнены с PostgreSQL.
- Подготовлен Python-скрипт преобразования данных
  и загрузки в PostgreSQL через pandas и SQLAlchemy.

### Запуск

1. Подключиться к PostgreSQL и выполнить telco_ddl.sql.
2. Выполнить transform_data.ipynb и загрузить данные через Python
   либо импортировать преобразованный CSV через DBeaver.
3. Выполнить задания из queries.sql по порядку.
4. Для DuckDB открыть отдельное подключение и выполнить duckdb_queries.sql.

Важно: telco_ddl.sql удаляет и заново создаёт таблицы схемы.
